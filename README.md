# SmartSol — сайт smartsol.pro

Сайт SmartSol: 1С, интеграции, сайты и приложения, боты и ИИ-консультанты, маркетинг
и свой продукт ФинПульс. Статический сайт на Astro, хостинг — GitHub Pages, заявки
с формы уходят на help@smartsol.pro через сервис Web3Forms. Своего сервера у сайта нет.

> Тексты — утверждённый документ `SmartSol_тексты_сайта.md` (русский). Казахский и английский —
> перевод по смыслу, в начале каждого файла пометка «ПЕРЕВОД: проверить носителем».
> Цен на сайте нет: «Стоимость — после бесплатного разбора задачи».
> Как устроен дизайн — в [DESIGN.md](DESIGN.md).

## Страницы

| Адрес (RU / KZ / EN) | Тексты |
| --- | --- |
| `/`, `/kz/`, `/en/` | `src/content/pages/<язык>/home.md` |
| `/services/` | `services.md` |
| `/products/` | `products.md` |
| `/products/finpuls/` | `products/finpuls.md` — единственное место, где упомянут FINTAX CONSULT |
| `/cases/` | `cases.md`, сами кейсы — `src/content/cases/<язык>/<slug>.md` |
| `/contacts/` | `contacts.md` |
| `/privacy/` | `privacy.md` — шаблон, проверить у юриста. **Оператор данных указан как «SmartSol» без реквизитов: политику нужно дополнить реквизитами (юрлицо, БИН/ИИН, адрес), когда они будут решены** — на всех трёх языках |
| `404.html` | `src/pages/404.astro` и словарь `src/i18n/ui.ts` |

Страница — это `seo` (title и description), `header` (заголовок, подзаголовок, кнопка к форме,
дополнительная кнопка `extra`) и `blocks` по порядку. Блоки:

| Блок | Что это |
| --- | --- |
| `hero` | Первый экран главной: заголовок, текст, кнопка к форме, кнопка WhatsApp, мелкая строка |
| `services` | Направления на линии главной, каждая строка — ссылка на раздел `/services/#…` |
| `feature` | Тёмный блок-акцент продукта с кнопками; `visual: calendar` — схема платёжного календаря |
| `cards` | Карточки по две в ряд: `href` — карточка-ссылка, `link` — кнопка внутри, `numbered` — номера |
| `steps` | Шаги работы — номера на линии |
| `cases` | Кейсы: `compact` — коротко на главной, иначе задача → что сделали → результат |
| `offers` | Разделы услуг и продуктов: текст, список, «Что получите» / «Результат» |
| `note` | Строка «Стоимость — …» с кнопкой |
| `text`, `faq`, `contacts`, `prose` | Текст, вопросы, каналы связи, тело Markdown (политика) |
| `lead` | Форма заявки на коралловой точке; `topic` приходит в письме строкой «Тема» |

Разметка в текстах: `[[слово]]` — коралловая плашка в заголовке, `**жирный**`,
`[ссылка](/services/)` — на казахской странице сама станет `/kz/services/`,
`[TODO: …]` — пометка «нужны данные» (список: `npm run todo`).

Новая страница: файл `src/content/pages/ru/<адрес>.md` — появится по адресу `/<адрес>/` сама,
попадёт в sitemap, а с переводами в `kz/` и `en/` получит hreflang.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Сервер разработки на http://localhost:4321 |
| `npm run build` | Сборка в `dist` (для проверки, в git не попадает) |
| `npm run preview` | Просмотр собранного `dist` |
| `npm run publish` | **Сборка для публикации** в `docs` — её отдаёт GitHub Pages |
| `npm run check` | Проверка типов TypeScript и Astro |
| `npm run assets` | Перерисовать картинки для соцсетей (`og*.png`) и иконки. Тексты на картинках — в `scripts/make-assets.mjs` |
| `npm run test:site` | Все страницы из sitemap на iPhone 13 и десктопе: ошибки консоли, битые запросы, горизонтальная прокрутка, h1/title/description, внутренние ссылки и якоря. Адрес — аргументом: `npm run test:site -- https://smartsol.pro` |
| `npm run todo` | Пометки `[TODO: …]` с файлом и строкой |

Требования: Node.js 22.23+ и npm; для `assets` и `test:site` один раз `npx playwright install chromium`.

## Форма заявки

Поля: имя, телефон или WhatsApp, компания (необязательно), задача, согласие на обработку данных.
Заявку принимает [Web3Forms](https://web3forms.com) и присылает письмом на help@smartsol.pro
(бесплатно до 250 заявок в месяц). В письме также тема (с какой страницы), язык, адрес страницы,
UTM-метки и откуда пришёл посетитель. Рядом с формой — кнопка «Или сразу напишите в WhatsApp».

Если заявка не ушла (нет интернета, сервис недоступен, ключ не задан), форма не стирается,
а ссылка «Отправить эту заявку в WhatsApp» открывает чат с уже вписанными данными.
Без JavaScript форма уходит обычным POST в Web3Forms. От ботов — скрытое поле-ловушка.

### Ключ Web3Forms

1. На [web3forms.com](https://web3forms.com) введите help@smartsol.pro — ключ придёт на эту почту.
2. Впишите его в `.env`: `PUBLIC_WEB3FORMS_KEY=…`
3. `npm run publish`, коммит и push.
4. В кабинете Web3Forms ограничьте ключ доменом `smartsol.pro`.

Ключ виден в коде страницы — так задумано сервисом: он только разрешает отправку писем
на help@smartsol.pro. Ограничение по домену не даёт пользоваться им с чужих сайтов.

## Переменные окружения

Файл `.env` (в git не попадает), образец — `.env.example`. Все переменные публичные.

| Переменная | Что это |
| --- | --- |
| `PUBLIC_WEB3FORMS_KEY` | ключ формы; пусто — форма предлагает отправить заявку в WhatsApp |
| `PUBLIC_YANDEX_METRIKA_ID`, `PUBLIC_META_PIXEL_ID` | счётчики; пусто — не ставятся. Подключите — допишите их в политику данных |
| `PUBLIC_PREVIEW` | `1` — тестовая сборка, на всех страницах `noindex` |

## SEO

- `title` и `description` — свои на каждой странице и языке; `canonical` и hreflang (ru, kk, en, x-default) — автоматически.
- `/sitemap.xml` собирается из контента (`src/pages/sitemap.xml.ts`), `public/robots.txt` указывает на него.
- Превью ссылки: `og.png`, `og-kz.png`, `og-en.png` (1200×630); иконки: `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`.

## Публикация на GitHub Pages

Репозиторий `undqpwm-svg/smartsol-site`, GitHub Pages отдаёт папку `docs` из ветки `main`.
Вместе с сайтом из `public/` копируются `CNAME` (smartsol.pro) и `.nojekyll`.

```powershell
npm run publish
git add -A
git commit -m "Что изменили"
git push
```

Через минуту-две изменения на smartsol.pro (ход выкладки — вкладка Actions репозитория).
Перед выкладкой: `npm run build`, `npm run preview`, `npm run test:site`.

DNS (Spaceship): A-записи `@` на 185.199.108.153 – 185.199.111.153, `www` — CNAME на
`undqpwm-svg.github.io`, `finpulse` — демо ФинПульса из другого репозитория. Домен вписывается
в репозитории: Settings → Pages → Custom domain `smartsol.pro`, галочка Enforce HTTPS.

В репозиторий не попадают (`.gitignore`): `.env`, ключи, исходники брендбука (PDF, PSD, AI, Figma),
клиентские материалы, `node_modules`, `dist`.

## Анимации и доступность

- По линии главной едет коралловая точка вместе с прокруткой, станции и номера шагов загораются,
  когда точка до них доходит. Первый экран мягко появляется, карточки — при прокрутке,
  столбики схемы ФинПульса вырастают. При «Уменьшить движение» анимаций нет, без JavaScript всё видно сразу.
- Навигация с клавиатуры: «Перейти к содержанию», видимый фокус, меню на `<dialog>`,
  вопросы на `<details>`.
